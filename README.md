# CodeVise

CodeVise is an AI-powered code analysis and programming assistance platform that I built to help developers understand, debug, and improve their code more efficiently.

While working on different coding projects, I realized that developers often spend a lot of time debugging code, understanding unfamiliar logic, and searching for optimization opportunities. I wanted to build a tool that could provide intelligent feedback and programming assistance in one place. That's how CodeVise came into existence.

# Features
- Analyze code snippets using AI
- Get suggestions for code improvements and optimizations
- Identify potential bugs and issues
- Receive explanations for complex code logic
- Get recommendations based on coding best practices
- User-friendly interface for interacting with the AI assistant

# How It Works
1. The user submits a code snippet through the application.
2. The backend processes the request and sends it to the Gemini AI API.
3. Gemini AI analyzes the code and generates suggestions, explanations, and optimization recommendations.
4. The results are displayed back to the user through the frontend interface.

# System Architecture
CodeVise follows a client-server architecture.

- The **frontend** provides an intuitive interface for users to interact with the platform.
- The **backend**, built using Node.js and Express.js, handles API requests and business logic.
- **Google Gemini AI** powers the code analysis and programming assistance capabilities.
- **MongoDB** is used for storing application-related data.

```
User
   ↓
Frontend (React)
   ↓
Node.js + Express Backend
   ↓
Gemini AI API
   ↓
MongoDB
```
